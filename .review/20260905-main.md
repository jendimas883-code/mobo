## 裁决（advisory 项的取舍）

- **flow 路径不调 mood.observe**（三席）：回复路径观察的是用户消息，flow 观察自己的输出会让正/敌意词启发式自我强化情绪。采纳：删除。
- **A3 gate 强回不经概率**（三席）：`score ≥ threshold` 的强制回复不查 probability，avoid 话题压不住它。裁决：文档化为有意语义——avoid 只治理概率路径，被点名必须回应（与 A3 自身"被点名仍必须回应"一致）。
- **A3 learn-skip 下沉 SQL**（三席）：`UPDATE … WHERE weight >= 0`，防管理台并发编辑竞态。采纳。
- **A2 interaction_count 语义**（三席）：公开路径**递增** interaction_count（Phase C 门槛与管理台依赖它）；familiarity-only 通过 observe 加参数把 warmth/trust/fatigue 增量置 0 实现，衰减语义不受影响（`_from_row` 每次写入物化衰减值）。采纳。
- **A5 mood 关闭时**（双席同向）：以基线值推导文风行（或不渲染与"情绪功能已关闭"矛盾的行）；置于 privacy/intent 行之后、倾向性措辞非指令。采纳。
- **B2 尊重 `proactive_global_enabled`**（三席）与 **flow token 必须走 `usage.record`**（双席）：采纳——总 kill switch 保持真实，token 对日软预算可见。
- **B1 生命周期**（双席）：`close()` 取消 flow 循环、`@flow.error` 处理器、tick 开头查 `_closing`。采纳。
